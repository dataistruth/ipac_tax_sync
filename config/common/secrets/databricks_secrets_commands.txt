Databricks CLI — create scope_ipacs_audit (PowerShell / CMD)
================================================================

Scope name : scope_ipacs_audit
Secret keys: SQL_SERVER_AUDIT_USERNAME, SQL_SERVER_AUDIT_PASSWORD

--- Interactive (prompts for values) ---

databricks secrets create-scope scope_ipacs_audit

databricks secrets put-secret scope_ipacs_audit SQL_SERVER_AUDIT_USERNAME

databricks secrets put-secret scope_ipacs_audit SQL_SERVER_AUDIT_PASSWORD

databricks secrets list-secrets scope_ipacs_audit


--- With Databricks profile ---

databricks secrets create-scope scope_ipacs_audit --profile YOUR_PROFILE

databricks secrets put-secret scope_ipacs_audit SQL_SERVER_AUDIT_USERNAME --profile YOUR_PROFILE

databricks secrets put-secret scope_ipacs_audit SQL_SERVER_AUDIT_PASSWORD --profile YOUR_PROFILE


--- Non-interactive (optional) ---

databricks secrets put-secret scope_ipacs_audit SQL_SERVER_AUDIT_USERNAME --string-value "YourAdminUser"

databricks secrets put-secret scope_ipacs_audit SQL_SERVER_AUDIT_PASSWORD --string-value "YourPassword"


--- PowerShell script (recommended) ---

.\config\common\secrets\setup_scope_ipacs_audit.ps1

.\config\common\secrets\setup_scope_ipacs_audit.ps1 -Profile YOUR_PROFILE

If create-scope fails because scope exists, skip it and run only put-secret.
